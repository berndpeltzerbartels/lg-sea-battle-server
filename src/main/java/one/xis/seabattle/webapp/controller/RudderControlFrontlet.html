Ruder einstellen

Diese Tasten verändern auf der Brücke den Ruderausschlag. Beim Loslassen bleibt das Ruder eingeschlagen. Eine neue seitliche Bewegung des direkten Ruder-Sticks übernimmt das Ruder wieder. Für Geschütze oder Ausguck kannst du dieselben Tasten zusätzlich unter „Zielen und Umschauen“ belegen.

Ruder links / nach linksNicht belegtOhne Controller: ← auf der Tastatur.
Ruder rechts / nach rechtsNicht belegtOhne Controller: → auf der Tastatur.
