Weitere Funktionen

Diese Belegungen ergänzen die Grundsteuerung. Gas festhalten lässt sich nur auf der Brücke aktivieren; eine neue Vor-/Rückbewegung des Sticks auf der Brücke löst es wieder. Nicht benötigte Funktionen dürfen frei bleiben.

Gas festhaltenNicht belegtOhne Controller: Mit ↑ / ↓ auf der Tastatur eine bleibende Fahrstufe wählen. Eine eigene Feststelltaste ist dafür nicht nötig.
Ausrichten / Boot auf PeilungNicht belegtOhne Controller: A zum Ausrichten der Geschütze oder 3, um das U-Boot auf die Sehrohrpeilung zu drehen.
Positionshilfe anzeigenNicht belegtOhne Controller: H auf der Tastatur.
